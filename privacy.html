Privacy Policy

Updated October 20, 2026

DuoLedger is a privately operated app for personal and two-person bookkeeping. This policy explains the Gmail connection and the records kept by DuoLedger.

Gmail access

With your consent, DuoLedger uses the Google OAuth scope https://www.googleapis.com/auth/gmail.readonly. This is a broad read-only permission that can view your Gmail messages and settings. DuoLedger cannot use this scope to send, edit, or delete your Gmail messages.

The current automated import searches within a date window and reads message metadata, including message identifiers, sender, subject, and received time. It retrieves message bodies for mail from configured supported senders and uses the content to recognize supported card transaction notices and related reconciliation messages. Unsupported messages are not intended to become ledger transactions. A sender or format filter is an application rule, not a restriction imposed by Google's OAuth permission.

Use and storage

DuoLedger uses Gmail data to show and reconcile transactions in the ledger, avoid duplicate imports, and pair related notices. The private backend stores extracted transaction details such as owner, card, merchant, amount, currency, transaction date and time, classification, status, and source receipt time. It also stores message/source identifiers and selected parsed notice metadata; for Rakuten notices this can include cardholder text and merchant details. The normal import path does not store an entire email body as a ledger record.

OAuth access and refresh tokens are stored in a restricted-access file on the private backend. They are used to request Gmail read-only access and refresh access automatically. The token is not placed in this website or a public repository. DuoLedger's ledger data and source associations are stored in its private PostgreSQL database. The website itself is static and has no forms, analytics, advertising scripts, or tracking cookies.

Sharing and Limited Use

DuoLedger uses Gmail data only to provide the visible bookkeeping and reconciliation features described here. It does not sell Gmail data or use it for advertising, credit decisions, or training generalized AI models. The automated import does not transfer message content or derived ledger data to advertising platforms, analytics providers, data brokers, or unrelated third parties. Google processes the account authorization and Gmail API requests; the private DuoLedger backend processes the returned data.

Human access to Gmail data is limited to the mailbox owner, a specifically authorized support request, a necessary security investigation, or a legal obligation. DuoLedger's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion, and revocation

No automatic retention deadline for imported ledger records or source associations is currently implemented. Deleting a transaction in DuoLedger marks it deleted from ordinary views and calculations, while retaining its record and source identifiers to prevent the same email from recreating it. There is no self-service “erase all Gmail-derived data” function at present. To request removal of Gmail-derived ledger data or the stored OAuth token, email the operator at the address below. The operator will verify and handle the request manually.

You can revoke DuoLedger's Gmail access at any time in your Google Account third-party access settings. Revocation stops future authorized reads. It does not automatically erase previously imported ledger records or the backend's stored token file; contact the operator for a separate removal request.

Contact and updates

Support and privacy contact: duoledger.support@gmail.com.
