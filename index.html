Gmail, with a clear purpose

Read-only access for transaction notices.

DuoLedger requests the Gmail gmail.readonly permission. Its import process searches recent mail, reads headers, and reads message bodies from supported senders to identify transaction notices. It creates or updates ledger records and keeps source identifiers to prevent duplicate imports.

The permission can technically view all messages and settings in the authorized mailbox; the current import process narrows what it processes by sender, date, and supported format. DuoLedger does not send email or change mailbox contents.
