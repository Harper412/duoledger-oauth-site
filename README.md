# DuoLedger OAuth website

Static homepage and privacy policy for the private DuoLedger bookkeeping app. This repository contains no app source, backend, credentials, database, or transaction data.

## Pages

- `index.html` — homepage
- `privacy.html` — English privacy policy
- `styles.css` — responsive styles
- `.nojekyll` — serve static files unchanged on GitHub Pages

GitHub Pages serves the `main` branch from `/(root)`. Open `index.html` and `privacy.html` locally to review the source pages.

The `github.io` hosting address alone does not prove domain ownership for a formal Google OAuth verification. Check Google's current domain requirements separately before submitting an OAuth verification request.
